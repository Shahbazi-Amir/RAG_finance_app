# APP_ONLY Web behavior (P0-4 bounded slice)
For a real private-staging app-only candidate, Ops config must set `send_mode=DISABLED` in `AUTH_STAGING_CONFIG_FILE` and `API_RUNTIME_PROFILE=APP_ONLY` in API. Server-side Next reads this authenticated, 0600 private profile; the browser cannot turn the engine back on through URL or localStorage. The existing ProductChat component disables textarea and Send, shows a readable Persian status and refuses form submit, while existing signed History remains GET only. The protected BFF proxy already rejects DISABLED Send with 503; new API app-only ASGI performs a second hard deny before request-body read or DB writes. No real Engine startup, token, model, user-generated Answer, or fake Citation. Existing synthetic browser tests remain isolated. Signed A/B real History in mounted Mac is separate.
