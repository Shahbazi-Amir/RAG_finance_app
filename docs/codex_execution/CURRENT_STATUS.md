## بازبینی پس از راه‌اندازی مجدد

هفت کانتینر در حال اجرا، پنج healthcheck سالم، Keycloak readiness برابر 200 و HTTPS ورودی با TLS معتبر برابر 302 بود. سقف Runner، قرارداد Locator، آزمون محصول و بازیابی کامل باز هستند. [شواهد](MAC_FIRST_START_FA.md)

## ادامهٔ C018 روی مبنای فریز‌شده

دو اجرای ایزوله با خاموش‌کردن spinning در ONNX در سقف ۱۸۰ ثانیه موفق شدند (بازیابی ۱۰۲٫۳۵ و 171.689 ثانیه، تکرار زندهٔ محصول اجرا نشد). Locator در انتظار تصویب نگاشت و شواهد اجازهٔ انتشار است. Attempt محصول، Refresh و Restore کامل باز هستند. آروان HOLD است. [گزارش فارسی](MAC_FIRST_START_FA.md)

## آخرین آزمون آمادگی اجرای واقعی

هفت سرویس سالم و Pin موتور مطابق بودند. آزمون مستقل با سقف ۱۸۰ ثانیه، exit 124 و توقف در batch چهارم ONNX داد. Attempt محصول و Refresh اجرا نشدند. Qdrant محصول 0555 است. Locator جداگانه BLOCKED و آروان HOLD است. ادعای زمان ۲۰ ثانیه نسخهٔ نوت‌بوک هنوز تأیید نشده است. [گزارش فارسی](MAC_FIRST_START_FA.md)

## استقرار اصلاح Qdrant روی API

ایمیج مشتق اجرا شد، شاخص اصلی 0555 ماند، lock در Scratch و شمارش ۳٬۴۸۸ بردار اثبات شد. هفت سرویس برقرار و HTTPS معتبر است. Runner مرجع با سقف ۱۸۰ ثانیه در Stage 4 با exit 124 متوقف شد. Attempt و Refresh اجرا نشدند. پیشنهاد ۳۰۰ ثانیه فقط برای یک probe آفلاین نیازمند تصویب است. [گزارش فارسی](MAC_FIRST_START_FA.md)

## نتیجهٔ آزمون تشخیصی ۳۰۰ ثانیه‌ای

Runner با خروج 124 و زمان بیرونی 305 ثانیه پایان یافت. CONTEXT_READY و رسید تازه صادر نشد. مرحلهٔ اسمبلی و serialization نتیجه مشاهده نشد. نمونهٔ پایانی CPU و I/O در لحظهٔ توقف موجود نیست. ONNX در ثانیهٔ ۱۹۹٫۰۴ شروع شد. سقف محصول ۱۸۰ ثانیه، Qdrant زنده سالم و Arvan HOLD است. Attempt و Refresh اجرا نشدند. بررسی نسخهٔ نوت‌بوک آغاز نشده است. [گزارش فارسی](MAC_FIRST_START_FA.md)

## NB23 V4 مستقل

هش موتور و رسید مطابق، ایمیج محلی ساخته شد و Worker واقعی سه Context آفلاین تولید کرد. زمان‌ها ۴۱٫۸۱، ۳۷٫۴۰ و ۴۴٫۶۳ ثانیه بودند. Top-10 و Context در هر سه مورد با مرجع اختلاف داشتند. اتصال محصول و UI و Freeze متوقف‌اند. [گزارش فارسی](MAC_FIRST_START_FA.md)

## UI محلی و مرز اختلاف V4

هفت سرویس قبلی دوباره فعال‌اند. Chrome محلی برای ورود و ظاهر UI باز شد. Q2 تا Hybrid تطبیق دارد و Context متفاوت است. V4 به محصول متصل نشده است. [گزارش فارسی](MAC_FIRST_START_FA.md)

## نامزد اصلاح Session

آزمون HTTP ایزولهٔ BFF موفق شد. نشست واقعی، Refresh و اتصال V4 هنوز تأیید نشده‌اند. هفت کانتینر قبلی خاموش یافت شدند و بدون تغییر حفظ شدند. [گزارش فارسی](MAC_FIRST_START_FA.md)

## نامزد تمدید Idle در Staging

آزمون PostgreSQL مستقل و Race ابطال موفق بود. نشست واقعی، Refresh و اتصال موتور به محصول هنوز پذیرفته نشده‌اند. [گزارش فارسی](MAC_FIRST_START_FA.md)
